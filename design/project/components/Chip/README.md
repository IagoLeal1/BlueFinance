Botão de escolha com ícone e nome, em linha que quebra. Usado para escolher categoria.

- `aria-pressed="true"` marca o selecionado: fundo `brand-soft`, borda `brand`, texto `on-brand-soft`.
- Escolha única na categoria; a ordem segue o uso mais frequente.
- Altura 40px com 4px de folga entre linhas — alvo de toque efetivo de 44px.
- O consumidor fornece: nome, ícone Lucide, estado.
