Quadrado de 40px com ícone que diz o tipo do lançamento pela cor e pelo desenho.

- `bf-cat--expense` (negative), `--income` (positive), `--invest` (invest), `--neutral` (transferências).
- O ícone é o da categoria (carrinho, carro, maleta); a cor é a do tipo, não da categoria.
- Sempre acompanhado do texto da linha; nunca sozinho para dar significado.
