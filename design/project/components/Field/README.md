Campo de texto com rótulo acima, dica opcional abaixo e estado de erro.

- Rótulo sempre visível (`bf-field__label`); placeholder é exemplo, nunca o rótulo.
- Fundo `surface-sunken`, borda `line-strong` 1.5px, foco com anel `focus`.
- Erro: `bf-field--error` deixa borda e dica em `negative`; a dica diz como corrigir.
- O consumidor fornece: rótulo, `input` (type certo: `text`, `date`, `search`), dica/erro.
